# ncSender.site

Source for [ncsender.xyz](https://ncsender.xyz), the ncSender landing page.

Plain static HTML, served by GitHub Pages from the `main` branch root. No build step.

- `index.html` — the page
- `assets/` — screenshots and logo
- `CNAME` — custom domain for GitHub Pages

Edit, commit, push. Pages redeploys within a minute or two.
